ContentPanel

Titled, collapsible section: a 56px header (caret, bold title, icon actions) over an optional body. Default (1px border) or borderless. Header actions are data-driven — at most 3 icons including the "..." trigger, the rest live in its label-only dropdown.

Figma node 126:4081 import { ContentPanel } from "figma-make-bridge" Source ↗

Playground

Click the caret or title to collapse and expand. Click the icons or open the "..." menu — the last action is shown below. Last action: none

Header actions

Three icons and no menu is the maximum. With a "..." menu the cap is two icon buttons plus "...". A fourth icon action is demoted into the menu.

Not expandable / header only

expandable={false} removes the caret and toggling. With no children there is no body.
