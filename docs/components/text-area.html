TextArea

Multi-line text input with label, helper/error text, a clear (×) button, two info-icon slots and a vertical resize handle. Hover/focus are plain CSS pseudo-classes; only the current value is real state.

Figma node 140:6170 import { TextArea } from "figma-make-bridge" Source ↗

Default (label top)

Type to see the clear (×) button appear. Drag the bottom-right handle to resize vertically; hover, then focus, to see focus keep its blue border.

Shown on the cluster details page.

labelPosition="left"

The label sits on the first line of text, not centred in the box.

Error state

Description must be under 100 characters.

Disabled & read-only
