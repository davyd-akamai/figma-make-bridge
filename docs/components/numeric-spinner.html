NumericSpinner

Single-number input with up/down chevrons. Min / max / step, Arrow and Home/End keys, hold-to-repeat chevrons, label, helper/error text.

Figma node 158:8448 import { NumericSpinner } from "figma-make-bridge" Source ↗

Default (label top)

Click or hold a chevron, press Arrow Up/Down, or type. An empty field starts at 0 on the first step.

labelPosition="left"

Label info icon, helper text

Hover or focus the info icon to see its Tooltip.

Between 1 and 10.

min / max / step

Min 0, max 10, step 2: steps that would leave the range are ignored; Home / End jump to min / max. The second field uses step 0.25.

Error state

Warning text

Disabled & read-only

Read-only renders plain text with no box or chevrons.
