TagInput & Tag

Field for entering several values as removable tags, with optional suggestions and free-text creation, built from the shared Tag chip. Hover/focus are plain CSS pseudo-classes; the tag list, search text and open state are the only real state.

Playground (label top)

Type ap to see matching options plus the + "typed" row. Enter picks the highlighted row (or adds the typed text); a comma or semicolon commits a tag; paste splits on commas, semicolons and newlines. Backspace on an empty input removes the last tag; ArrowLeft moves onto the tags, then Backspace/Delete removes the focused one.

Tags:

labelPosition="left"

The label is centred on the first row, 12px from the field.

Filled and multiline

Tags wrap onto extra rows; the box grows to 100px, then the tag area scrolls. No "+N" collapse.

Error

Invalid tags are the consumer's call (invalid: true on a tag). errorText turns the box red and shows the message; set both.

Locked tag and options only

removable: false with a lock icon keeps a tag permanently. creatable={false} allows only the options list (no + "typed" row).

Disabled and read-only

Disabled shows only the greyed tags (no input, chevron or ×). Read-only drops the box entirely.

Tag

Default (hover for the darker border, Tab then focus for blue), with lock icon, invalid, disabled, read-only, not removable, and the "+N" overflow chip. Click an × to remove it.
