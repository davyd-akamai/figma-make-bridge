ProgressBar

Horizontal bar showing measurable progress of a task, with optional title, right-aligned status text, description and link. value/max drive the fill and the state is derived from them (empty, in progress, success); error is always set explicitly. The in-progress fill animates a light band across the gradient.

Empty, in progress, success and error, large (8px) then small (4px). With no text, give it an aria-label.
