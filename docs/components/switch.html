Switch

Immediate on/off toggle for a setting. A visually hidden native <input type="checkbox" role="switch"> inside a <label>, with a custom track and knob; large (48×24) by default, small (40×20) for tables and dense lists.

Figma node 129:5474 import { Switch } from "figma-make-bridge" Source ↗

Large (default)

Off, on, disabled off, disabled on, and a bare switch with no label (needs an aria-label). Click, hover, and Tab/Space all work.

Small

Reserved for tables and dense lists where a 24px control would crowd the row.

Controlled

onChange receives the new boolean. Current value: on
