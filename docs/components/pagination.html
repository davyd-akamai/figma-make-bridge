Pagination

40px bar for paging through a large data set: total count, page-size picker, "1 - 20 of 50" range and previous/next chevrons. Table and List variants, plus an opt-in selection mode on lists (Select / Deselect / Selected only). It never slices data or stores the selection — it fires callbacks.

Table

Item counter on the left. Click the chevrons or open the page-size menu (changing the size keeps the first visible item on screen). State: page 1, size 20

List

variant="list" puts the page-size picker on the left (95 items here).

List selected

variant="list" selectable. Click items to toggle them; "Select" selects the whole list, "Deselect" clears, and "Selected only" hides the unselected items. The consumer owns the selection and the filtering — the page controls are not shown in this mode.

Disabled / empty
