NotificationBanner

Full-width inline message with a status icon, text, an optional action and an optional dismiss button. Five types. Width fills its parent, clamped between 240px and 1000px.

Figma node 123:5210 import { NotificationBanner } from "figma-make-bridge" Source ↗

Types

Info, warning, success, error and secondary, without the dismiss button (dismissible={false}).

Action + dismiss

The action is a link-variant Button passed through the action slot. Click × to dismiss: the demo plays the consumer's role and removes the banner itself.

Long text

Text wraps; the icon and × stay aligned to the first line.
