Release notes

What changed in figma-make-bridge for designers and Make users — new components, improvements and bug fixes, newest first. Grouped by package version; changes not yet in a published version are listed under Unreleased.

Last updated 2026-10-30

Unreleased

TypeChange
New componentTooltip — a short label that appears next to a control on hover or keyboard focus. Wraps any control, sits on the top, bottom, left or right with an optional arrow, flips to the opposite side when there is no room, and closes with Esc.
ImprovementInfo icons now show a tooltip on hover and keyboard focus in TextField, TextArea, Checkbox, RadioButton, Select, TagInput and Table column headers, instead of the browser's plain hint (or nothing).
ImprovementOne new icon: the tooltip arrow.
New componentTagInput — add several values as removable tags. Suggestions appear as you type, with a + "typed" option to create a new tag; Enter, comma or paste adds tags. Supports top, left or no label, a label info icon, helper and error text, per-tag error styling, a clear-all (×) button, and disabled and read-only states. Tags wrap and the field scrolls once it passes 100px tall.
New componentTag — a removable pill chip with an optional leading icon, error, disabled and read-only styling, and a "+N" overflow chip.
ImprovementTwo new icons: a 12px close and a 12px lock (used by Tag).
New componentTextArea — multi-line text input with a label (top, left or none), helper and error text, a clear (×) button, an info icon beside the field and one next to the label, and a drag-to-resize handle. Supports default, placeholder, hover, focus, filled, disabled, error and read-only states.
